# Schemata Codegen: Language Matrix

Cross-language comparison of the 12 validator emitters generated by `schemata-codegen`.

All emitters consume the same `ValidatorAction[]` IR from `plan-validators.ts` and produce functionally equivalent validation code. Differences are syntactic, idiomatic, and dependency-related.

## Language Requirements

| Language | Min Version | Reason | Output File |
|----------|-------------|--------|-------------|
| C | POSIX C99 | `regex.h`, `strcmp`, standard library | `.c` + `.h` |
| Rust | 2018 edition | `pub(crate)`, module paths | `.rs` |
| Go | 1.1+ | `range`, `append` | `.go` |
| Python | 3.9+ | `list[list[str]]` builtin generic syntax | `.py` |
| Kotlin | 1.4+ | `getOrNull()`, standard library | `.kt` |
| Java | 17+ | `record` type for ValidationError | `.java` |
| Swift | 5.0+ | `String` ranges, `contains(where:)` | `.swift` |
| Dart | 2.0+ | `const` constructors, `codeUnits` | `.dart` |
| PHP | 8.0+ | `match` expression, `str_starts_with` | `.php` |
| C# | 9.0+ | `record` type (9.0), switch expression (8.0) | `.cs` |
| C++ | C++17 | `std::all_of`, `<algorithm>`, structured bindings | `.hpp` |
| Ruby | 2.7+ | `Struct.new`, `match?`, `any?` | `.rb` |

## API Adapter Modes

C and Rust support library-specific adapter modes. All other languages are generic-only.

| Language | Mode | Tag Parameter Type | Notes |
|----------|------|--------------------|-------|
| **C** | `generic` (default) | `const char *const *const *tags, const int *tag_lens, int num_tags` | Plain arrays, any project |
| **C** | `nostrdb` | `const struct ndb_note *note` | Uses `ndb_iterator`, requires `nostrdb.h` |
| **Rust** | `generic` (default) | `&[&[&str]]` | Slice of string slices, any project |
| **Rust** | `nostr` | `&Tags` | nostr crate v0.37+, uses `.as_slice()` |
| **Rust** | `nostrdb` | `&[Tag]` | nostrdb-rs, uses `.get_str()` |
| Go | generic | `[][]string` | |
| Python | generic | `list[list[str]]` | |
| Kotlin | generic | `List<List<String>>` | |
| Java | generic | `List<List<String>>` | |
| Swift | generic | `[[String]]` | |
| Dart | generic | `List<List<String>>` | |
| PHP | generic | `array` | `array<array<string>>` by convention |
| C# | generic | `IReadOnlyList<IReadOnlyList<string>>` | Immutable interface |
| C++ | generic | `const std::vector<std::vector<std::string>>&` | |
| Ruby | generic | untyped (`Array`) | Duck-typed |

## ValidatorAction Support

All 12 emitters handle all 6 action types. No gaps.

| Action | Description | All 12? |
|--------|-------------|---------|
| `check_min_tags` | Minimum tag count | Yes |
| `require_tag` | Tag must exist matching criteria | Yes |
| `validate_optional_positions` | Constrained optional positions within a tag | Yes |
| `per_item_conditional` | If tag[0] matches name, validate rest | Yes |
| `array_level_conditional` | If any tag has name, require another tag | Yes |
| `any_of_group` | At least one of N tag patterns must match | Yes |

## PatternCheck Support

A majority of schemata regex patterns (~74%, 23 of 31 in the test suite) classify as native checks, avoiding regex dependencies. The test enforces a >= 50% floor.

| Pattern | Description | All 12? |
|---------|-------------|---------|
| `hex64` / `hex128` / `hex40` | Fixed-length hex string | Yes |
| `hex_range` | Variable-length hex (`{min,max}`) | Yes |
| `hex_prefixed` | Hex with prefix (e.g. `0x`) | Yes |
| `all_digits` | Numeric string (optional `-` sign) | Yes |
| `starts_with_any` | Prefix check (`https://`, `wss://`, etc.) | Yes |
| `chars_in` | Character set with length bounds | Yes |
| `regex` (fallback) | Full regex when no native check fits | Yes |

## Regex Dependencies

Regex is only imported when a kind schema requires a pattern that can't be classified as a native check (~26% of patterns).

| Language | Regex Source | Import | Conditional? |
|----------|-------------|--------|--------------|
| C | POSIX `regex.h` | `#include <regex.h>` | Yes |
| Rust | `regex` crate | `use regex::Regex` | Yes |
| Go | stdlib `regexp` | `import "regexp"` | Yes |
| Python | stdlib `re` | `import re` | Yes |
| Kotlin | stdlib `kotlin.text` | `import kotlin.text.Regex` | Yes |
| Java | stdlib `java.util.regex` | `import java.util.regex.Pattern` | Yes |
| Swift | Foundation | `import Foundation` | Yes |
| Dart | builtin `RegExp` | (none needed) | N/A |
| PHP | builtin `preg_match` | (none needed) | N/A |
| C# | stdlib `System.Text` | `using System.Text.RegularExpressions` | Yes |
| C++ | stdlib `<regex>` | `#include <regex>` | Yes |
| Ruby | builtin `.match?` | (none needed) | N/A |

## Null Safety / Bounds Checking

| Language | Strategy |
|----------|----------|
| C | Manual `_tag_len > 0 && _tag[0]` guard before dereference |
| Rust | `.get(i).copied()` returns `Option`, safe by default |
| Go | `len(t) > i` bounds check before access |
| Python | `len(t) > i` bounds check before access |
| Kotlin | `.getOrNull(i)` with Elvis operator |
| Java | `t.size() > i` check, `"literal".equals(x)` to avoid NPE |
| Swift | `.count > i` check before access |
| Dart | `.length > i` check before access |
| PHP | `isset($t[$i])` or `count($t) > i` |
| C# | `.Count > i` check before access |
| C++ | `.size() > i` check before access |
| Ruby | Direct index (returns `nil` safely), explicit `.nil?` when needed |
